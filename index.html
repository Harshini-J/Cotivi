Chart evidence extractor

Paste an unstructured chart note and extract diagnoses, procedures, and medications, each grounded in the exact sentence it came from. Two extraction engines: an offline keyword baseline, and a live Claude API call that returns cited findings and gets automatically checked against the source text.

Calls the Claude API directly from this page using Anthropic's documented browser-access header — a bring-your-own-key pattern for demos. Rule-based mode uses lexicon matching, kept as a fast offline baseline. LLM mode sends the note to Claude (claude-sonnet-4-6) or Gemini (gemini-3.6-flash, free tier) with instructions to return only findings quoted verbatim from the note; every returned sentence is then checked against the source text client-side, and anything not found verbatim is discarded and shown separately rather than trusted. That verify-before-trust step is the same grounding pattern the accompanying report recommends scaling into production chart review. Sample notes are synthetic and contain no real patient information.
